# Local music tutorial

Use this tutorial to play music already stored on your computer.

## Before you start

 Supported formats are MP3, FLAC, WAV, OGG, Opus, M4A, AAC, ALAC, AIFF, and WebM.

## Add and play a folder

1. Open `music-terminal-player.exe`.
2. Select `Play local folder`, then press `Enter`.
3. Select `Add folder`, then press `Enter`.
4. Type or paste the full folder path. Example:

   ```text
   D:\Music\The-V-songs
   ```

5. Press `Enter`. The player scans the folder and its subfolders.
6. Select `Play in order`, `Shuffle`, or `Recently added`, then press `Enter`.

The folder is saved for later. The menu displays only its final name, such as `The-V-songs`, but the full path remains stored internally.

## Play a saved folder later

1. Open `Play local folder`.
2. Select the saved folder name.
3. Press `Enter`.

## Remove a saved folder

1. Open `Play local folder`.
2. Select `Forget location`.
3. Select the folder and confirm.

This removes only the saved shortcut. It does not delete the folder or any music files.

## Useful playback keys

| Key | Action |
| --- | --- |
| `p` or `Space` | Play or pause |
| `n` | Next song |
| `v` | Previous song |
| `r` | Toggle shuffle |
| `l` | Change loop mode |
| `u` | Open the queue |
| `Up` / `Down` | Change volume by 10% |
| `Left` / `Right` | Change volume by 1% |
| `b` or `Esc` | Return to the previous menu |
| `q` or `Ctrl+C` | Quit completely |

## If no songs appear

- Check that the folder path is correct.
- Check that the folder contains a supported audio format.
- Check that the files can be opened by your Windows account.

For every option and command, see the [full usage guide](usage.md).
